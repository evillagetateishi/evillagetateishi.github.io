# rooms.json 編集ガイド

客室の情報は `data/rooms.json` の1か所にまとめてある。
`index.html` は `scripts/generate.py` がこの JSON から組み立てるので、
**HTML を直接編集しない**。編集して push しても、CI の生成一致検査で落ちる。

```
data/rooms.json          ← 直すのはここだけ
templates/index.html.tmpl ← 見た目・文章の型（部屋データ以外を変えるとき）
index.html               ← 生成物。手で編集しない
```

## 1. このリポジトリは「公開」されている

GitHub Pages で世界中から読める。GitHub 上のソースも誰でも閲覧できる。
つまり `data/rooms.json` に書いた内容は、**書いた瞬間に公開したのと同じ**。
一度 push すると、あとで消してもコミット履歴に残る。

### 書いてよいもの（公開情報）

- 部屋コード（EVT101 など）、部屋名、紹介文
- 定員、ベッド構成、広さ、間取り
- 設備（キッチン、洗濯機、Wi-Fi など、Airbnb の掲載と同じ範囲）
- 写真のファイル名と alt 文
- Airbnb の公開ページ URL
- 評価・レビュー件数・バッジ（Airbnb 上で誰でも見られる値）
- 旅館業の許可番号（※表示は現在オフ。下の「許可番号」を読むこと）

### 絶対に書いてはいけないもの

- **暗証番号・PIN・キーボックスの番号・スマートロックの解錠コード**
- **Wi-Fi のパスワード**
- ゲストの氏名・連絡先・予約番号など、宿泊者に関する一切の情報
- API キー、アクセストークン、管理画面のログイン情報
- 社内向けのメモ、原価、清掃業者との取り決め、非公開の運用ルール
- 近隣住民や取引先に関する記述

`scripts/validate.py` がこれらを機械的に弾く。
4桁以上の数字列は暗証番号の混入を疑って**既定で不合格**にしている
（Airbnb の物件 ID と許可番号だけは正当な値として通す）。
検査に引っかかったら、回避策を探す前に「それは本当に公開してよい値か」を先に考える。

## 2. よくある編集

### 部屋を一時的に止める

満室・改装・掲載停止のときは `active` を `false` にする。

```json
{ "code": "EVT202", "active": false, ... }
```

その部屋はサイトの一覧から消える。データは残るので、`true` に戻せば元通りになる。
（検証済み: 停止 → 生成 → 復元 → 生成 で、停止前と1バイトも違わない HTML に戻る）

### 文章や設備を直す

`name` / `desc` / `beds` / `size` / `amenities` を書き換える。
`amenities` と `layout` と `photo.alt` は英語 (`en`) と日本語 (`ja`) の両方を書く。
日本語は現時点のサイトには出ないが、客室個別ページを作るときに使う。

### 写真を差し替える

`images/rooms/evtNNN.png` を**同じファイル名のまま**置き換える。
JSON を触る必要はない。ファイル名を変える場合は `photo.file` も直す。
`photo.alt` は写真の内容を説明する文にする（見えない人に伝わる言葉で書く）。

### 部屋を追加する

`rooms` 配列に1件足す。`code` は `EVT` + 3桁。
写真を `images/rooms/` に置いてから追加すること（実在しないと検査で落ちる）。

## 3. 許可番号

旅館業法の許可番号は各部屋の `license.number` に入れてある。
ただし `license.display` は **`false` 固定**で、サイトには出していない。

表示するかどうかは井口さんの裁定事項なので、**指示なしに `true` へ変えない**。
`validate.py` は `display` が `false` 以外だと不合格にする。

## 4. 直したあとにやること

```bash
python scripts/validate.py     # 中身の検査
python scripts/generate.py     # index.html を作り直す
```

両方通ったら、`data/rooms.json` と `index.html` を一緒にコミットする。
`index.html` だけ、`rooms.json` だけ、のどちらかを忘れると CI が落ちる。

## 5. 触ってはいけないファイル

- `google2bb9730f466ce625.html`
  Google Search Console の所有権確認ファイル。消すと検索での計測が止まる。
  生成の対象外で、CI が存在を見張っている。

## 6. アクセス解析

`index.html` の `</head>` 直前に Matomo の計測タグが入る（生成時に自動で差し込まれる）。
Cookie を使わない設定 (`disableCookies`) なので同意バナーは要らない。
Airbnb の予約ボタンを押すと `airbnb / click / 部屋コード` として記録される。
接続先と site_id は `scripts/generate.py` の先頭に定数として書いてある。
